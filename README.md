# Dify PR Review Skill

Review Dify pull requests using yunlu.wen / wylswz's technical priorities and concise, pragmatic review style.

## Install

Use the npm-distributed [Skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add wylswz/review-dify-prs --skill dify-personal-pr-review
```

Choose your coding agent when prompted. Add `-g` for a user-level installation across projects:

```bash
npx skills add wylswz/review-dify-prs --skill dify-personal-pr-review -g
```

Preview the available skill without installing:

```bash
npx skills add wylswz/review-dify-prs --list
```

No separate npm package is required; the CLI installs the skill directly from this repository.
